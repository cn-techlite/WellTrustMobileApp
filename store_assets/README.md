# WellTrust store assets

All images use fictional sample data and contain no real client or staff information.

## Google Play upload folders

| Play Console field | Folder | Files | Size |
| --- | --- | ---: | --- |
| App icon | `google_play/icon/` | 1 | 512 × 512 |
| Feature graphic | `google_play/feature_graphic/` | 1 | 1024 × 500 |
| Phone screenshots | `google_play/phone/` | 8 | 1080 × 1920 |
| 7-inch tablet screenshots | `google_play/tablet_7/` | 8 | 1440 × 2560 |
| 10-inch tablet screenshots | `google_play/tablet_10/` | 8 | 2160 × 3840 |

The Google screenshot sets use an exact 9:16 portrait ratio.

## Rebuild

The UI images are generated by `test/store_assets_generator_test.dart`:

```sh
flutter test test/store_assets_generator_test.dart --update-goldens
```

Flutter golden images include an alpha channel by default. Before uploading a regenerated set, flatten it with:

```sh
find store_assets/google_play store_assets/apple -type f -name '*.png' -print0 \
  | xargs -0 swift tool/strip_png_alpha.swift
```

The feature graphic background was produced with OpenAI's built-in image generation tool using the project's navy, teal, and gold palette. Its source is in `source/feature-background.png`.
